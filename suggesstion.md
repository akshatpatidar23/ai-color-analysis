# Product & Technical Review: Zenith, J.e.r.k, and In-House AI

### 1. Zenith Fashion & Colour Analysis AI
* **Lighting Normalization:** Add automated histogram equalization / white-balance correction before clustering to prevent indoor warm lighting from misclassifying cool undertones.
* **Granular Palettes:** Expand from 4 seasonal classifications to the 12-season sub-palette system (e.g., Deep Autumn, Light Spring) to improve personalized clothing recommendations.

### 2. User Experience & E-Commerce Integration
* **Direct Wardrobe Matching:** Allow users to instantly filter catalog clothing on `thezenithindia.in` and `thejerk.in` that match their detected palette hex codes.
* **Instant Camera Capture:** Add real-time webcam capture alongside file upload on mobile browsers to reduce user friction.
